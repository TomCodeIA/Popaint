# Popaint

Jeu Roblox : éclate des bulles qui repeignent un monde gris en studs. Développé avec l'IA.

- **Obtenir le jeu** : `tools/setup.sh` puis `tools/check.sh` fabrique et vérifie `build/Popaint.rbxl`.
- **L'installer** : Roblox Studio → File → Open from File → `Popaint.rbxl`, puis
  File → Publish to Roblox As… → ton jeu existant → Overwrite.
- **Mettre à jour le contenu** : tout est dans `src/Shared/Content/` (voir les explications en tête de
  chaque fichier) ; les règles pour l'IA sont dans `CLAUDE.md`, l'historique dans `CHANGELOG.md`.
